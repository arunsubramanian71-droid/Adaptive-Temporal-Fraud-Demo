Research question

Do heterogeneous relational structure and temporal behaviour improve fraud detection and the discovery of coordinated groups compared with strong tabular models, particularly on future data and under drift?

Data: the IEEE-CIS Fraud Detection transactions (Kaggle; not redistributed), split by time: training days 1-121, validation days 122-151, held-out days 152-182 (sealed). Every number on this page is read from the project's recorded result files when the page loads; none is typed into the page.

How the system works

  1. Chronological splitpreprocessing fitted on training days only; no row ever sees a later row
  2. Leakage-safe featurestransaction features and 40 backward-looking graph features over cards, pseudo-accounts, devices and network proxies
  3. Modelslogistic regression, random forest, XGBoost; GraphSAGE, GAT and Temporal GraphSAGE with GRU entity memory
  4. Validation evaluationprecision-recall first (fraud is rare), drift and adaptive refresh, candidate-community discovery
  5. Servingthis local API and dashboard; a score is a model output, not evidence of fraud

Limitations

  • Every result is a validation-period result, and most models were tuned on that period: the numbers are optimistic by an unmeasured amount.
  • The held-out period is sealed; no model has been scored on it.
  • GAT did not converge within its budget, so its result cannot separate a weaker model from under-training.
  • The three seeds share data; they are not independent replications.
  • The data has no labels for coordinated groups: communities are candidates only, and nothing here shows that any group is fraudulent or coordinated.
  • The neural models score whole days of graph state and are not served row by row; demonstration scoring uses a synthetic bundle.
