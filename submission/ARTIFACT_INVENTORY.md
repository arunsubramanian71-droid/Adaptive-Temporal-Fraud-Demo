## 4. Must never be published

The IEEE-CIS files and every file derived from them row by row: predictions, per-transaction explanations, feature tables, encoders with raw vocabularies, entity id maps, the split record. The same applies to anything from the held-out period (none exists yet). A trained model file is not row-level data, but it is derived from the competition data, so the project does not distribute model files. Screenshots must not show IEEE-CIS rows: the published dashboard screenshots use synthetic placeholder rows for the research tab (`experiments/phase13_serving_dashboard/test_results/browser/`).

**Already published by mistake:** the six per-transaction evidence files listed above are in 21 historical commits of the public repository `Adaptive-Temporal-Fraud`. They are no longer tracked at the branch tip. A separate repository `Adaptive-Temporal-Fraud-Research` (private on 2026-10-22, single commit `93f02da`) contains them at its tip. See `HELDOUT_DECISION_PACKAGE.md` section 7.

## 5. File-level release manifest

`scripts/make_release_manifest.py` writes `submission/RELEASE_MANIFEST.json`: every release file with its SHA-256, category and state against the published `main` (unchanged, modified or added), the files the release would drop, and the withheld groups with how a clone obtains each (groups can overlap, for example the demonstration bundles are also `.joblib` files).

## 6. No secrets

The project uses no credentials, tokens, API keys or environment variables, so there is no `.env` file and no `.env.example` is needed. A scan of the tracked files and of the 2026-10-22 changes found no credential patterns.
